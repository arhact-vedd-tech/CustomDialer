# Спека: экраны и навигация

## Карта навигации

```
Onboarding (одноразово)
     │
     ▼
┌────────────────────────────────────────┐
│  Main (BottomNavigation)               │
│  ┌────────┬────────┬────────┬────────┐ │
│  │ Dialer │  Log   │Contacts│Settings│ │
│  └────────┴────────┴────────┴────────┘ │
└────────────────────────────────────────┘
     │
     ├── In-Call (overlay, full-screen)
     │
     ├── RuleList ──► RuleEditor
     │
     ├── Exceptions ──► (редактор исключения)
     │
     ├── Whitelist ──► (редактор белого списка)
     │
     └── SemiAutoSheet (bottom sheet поверх Dialer)
```

---

## 1. Onboarding

| Элемент | Описание |
|---|---|
| Шаги | 1) выбор роли Dialer 2) разрешения 3) дефолтные исключения 4) готово |
| Кнопка | «Продолжить» / «Запросить роль» |
| Состояния | роль не получена / получена; разрешение — granted / denied / permanently denied |

Навигация: после завершения → Main/Dialer. Повторно не показывается. Если роль сброшена системой — баннер в Dialer.

---

## 2. Dialer

| Зона | Элементы |
|---|---|
| Верх | T9-поле ввода, кнопка «Вставить», кнопка очистки |
| Центр | превью контакта (если матч), иначе пусто |
| Кнопки быстрых префиксов | ряд программируемых кнопок (`+7`, `8`, `#31#`, `9`), свайп-скролл |
| Клавиатура | 0–9, `*`, `#`, `,`, backspace |
| Низ | кнопка «Позвонить», индикатор SIM (если 2 SIM — селектор) |

**Состояния:** пусто / ввод / матч контакта / нет SIM.

**Действия:** тап «Позвонить» → `OutgoingCallOrchestrator.dial`. Long-press «Позвонить» → полуавто sheet (если применимо).

---

## 3. In-Call

Overlay поверх всего. Не входит в BottomNavigation.

| Зона | Элементы |
|---|---|
| Верх | имя/фото, номер, статус (звонок/удержан/конференция), таймер |
| Центр | Hold / Mute / Speaker / DTMF / End |
| DTMF | отдельная панель-клавиатура (overlay) |
| SIM-индикатор | бейдж активной SIM |
| Конференция | список участников, merge/split |

**Состояния:** dialing / active / held / conference / disconnected.

Источник данных — `InCallService.onCallAdded` / `onCallRemoved`. UI подписывается на Flow из `CallRepository`.

---

## 4. Call Log

| Зона | Элементы |
|---|---|
| Верх | фильтр-чипы: Все / Пропущенные / Исходящие / Входящие |
| Список | группировка по дате, иконка типа, имя/номер, время, длительность |
| Бейдж | «префикс» на исходящих, где `CallLogExtras.appliedRuleId != null` |
| Действие | тап → orchestrator.dial (повтор); long-press → удалить / позвонить с выбором правила |

**Состояния:** пусто / список / фильтр активен.

Источник: системный `CallLog` + left join `CallLogExtras`.

---

## 5. Контакты / Избранное

| Зона | Элементы |
|---|---|
| Верх | поиск |
| Вкладки | Контакты / Избранное |
| Список | аватар, имя, метка (если есть), кнопка звонка |
| Карточка | фото, имя, номера, метки, кнопка «Звонок», «SMS» |

Метки (локальные) — редактируются в карточке контакта. Используются в правилах и исключениях.

---

## 6. Правила (список)

| Зона | Элементы |
|---|---|
| Верх | «+» добавить правило |
| Список | drag-and-drop, toggle enabled, название, краткое условие → действие, приоритет (номер) |
| Пусто | «Правил нет. Добавить» |

**Состояния:** пусто / список / drag в процессе.

Источник: `Rule` + `RuleCondition` + `RuleTarget`.

---

## 7. Правило (редактор)

| Секция | Поля |
|---|---|
| Название | text |
| Условия | список: тип (LENGTH / STARTS_WITH / LABEL) + значение; «+ добавить условие» |
| SIM | dropdown: любая / SIM1 / SIM2 |
| Действие | тип (STRIP / PREPEND / STRIP_PREPEND), значение; для STRIP — число; для PREPEND — строка |
| Режим | автоматический / полуавтоматический (toggle) |
| Preview | «Вход: 89991234567 → Выход: 9991234567» (live) |
| Сохранить / Удалить | — |

**Валидация:** пустое название, пустые условия, невалидный номер в preview → кнопка «Сохранить» неактивна.

**Состояния:** создание / редактирование / ошибка валидации.

---

## 8. Исключения

| Зона | Элементы |
|---|---|
| Верх | «+» добавить |
| Список | номер или метка, иконка замка у залоченных (`112`, `101`, `102`, `103`) |
| Залоченные | не удаляются, не редактируются |
| Удаление | swipe / long-press |

Источник: `Exception`.

---

## 9. Белый список

Аналогично Исключениям, но:

| Элемент | Описание |
|---|---|
| Список | номер/метка → правило X |
| Добавление | выбор правила из dropdown + номер/метка |

Источник: `RuleTarget`.

---

## 10. Полуавто bottom sheet

| Элемент | Описание |
|---|---|
| Заголовок | «Как позвонить на 89991234567?» |
| Опции | «Напрямую» / «Правило R» (все подходящие, с preview) |
| Отмена | свайп вниз |

Появляется по long-press «Позвонить» или если правило помечено полуавтоматическим.

---

## 11. Настройки

| Секция | Элементы |
|---|---|
| Внешний вид | тема (системная/светлая/тёмная), динамические цвета |
| Префиксы | «Правила», «Исключения», «Белый список», «Быстрые кнопки» |
| Данные | экспорт JSON, импорт JSON |
| Диагностика | версия, статус роли Dialer, статус разрешений, лог последних ошибок |
| О приложении | версия, лицензии |

## Общие правила UI

- Material 3, динамические цвета, светлая/тёмная.
- Все списки — `LazyColumn` с `key`.
- Пустые состояния — иконка + текст + действие.
- Ошибки валидации — inline, не тост.
- Деструктивные действия — диалог подтверждения.
- Навигация — Navigation Compose, back-stack предсказуемый.
